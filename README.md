# CodeRun Studio\n\nA responsive browser-based coding playground. HTML/CSS/JavaScript preview runs in a sandboxed iframe; Python uses Pyodide in the browser; other languages use a configurable Piston-compatible execution API.\n\n## Render deployment\n- Runtime: Python\n- Build command: `pip install -r requirements.txt`\n- Start command: `gunicorn app:app`\n- Environment variables (optional): `PISTON_API_URL` (default `https://emkc.org/api/v2/piston`), `PISTON_API_KEY` (if your execution service requires authentication).\n\nThe public Piston service may require authorization or impose usage limits. For reliable multi-language execution, configure an authorized Piston-compatible endpoint or self-host a sandboxed execution engine. Do not execute untrusted code directly on the web server.\n
